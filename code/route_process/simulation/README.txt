TC264 全赛道循迹仿真

双击 run_simulation.bat 可重新生成全部结果。

默认输出：
- 546 张 1280x720 效果帧，20 FPS，共 27.30 秒。
- route_tracking_simulation.mp4：完整 H.264 视频。
- snapshots：每个可见赛道段的起点、中段和终点截图。
- trajectory.jpg：彩色全赛道覆盖轨迹，数字 1-6 表示各段起点。
- metrics.csv / summary.json：逐帧数据和汇总结果。

照片中的赛道在画面边缘离开后又重新进入，并在中央存在没有选路逻辑的
交叉区域，右上急回头弯也超出了单帧前视选线范围，因此视频分为六个明确
标注的可见段。各段之间重置车辆位置，
不会绘制穿过蓝色地面的虚假连接线。每一段的图像识别、舵机 PD、差速和
速度 PID 都使用 python/route_algorithm.py 中与工程 C++ 逐项对应的算法。

图例：
- 红点：左右边界
- 绿点：计算中心线
- 青线：当前段车辆轨迹
- 蓝灰线：已完成段车辆轨迹
- 黄色四边形：虚拟摄像头视野
- 橙色区域：仿真的上坡负载区
